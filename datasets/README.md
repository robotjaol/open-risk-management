# Datasets

Version 0.1.0. All data in this folder is synthetic and generated by code in this repository.

| Name | Rows | Purpose |
|---|---|---|
| retail_loans_dev | 15000 | default model development |
| retail_loans_monitoring | 6000 | drift monitoring |
| loan_book | 5000 | ECL inputs |
| market_returns | 3000 | daily returns for VaR and ES modules |

Files: `catalog.csv` lists every dataset with checksum. Each `synthetic/<name>.yaml` is a dataset card with the generator call, seed, columns, generating process, leakage risks and representativeness.

Folders `raw/` and `processed/` do not exist yet, because no real dataset has been added. They will be created with the first real dataset. See [docs/dataset_guide.md](../docs/dataset_guide.md).

Regenerate with `python tools/build_datasets.py`. The output is deterministic, so the checksums in the cards must not change.

## Disclaimer

Synthetic data does not represent any real bank, market or borrower. Do not describe results on it as findings about the real world.
