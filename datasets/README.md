# Datasets

Version 0.2.0. Two kinds of data: synthetic data generated by code in this repository, and real open data downloaded from public sources with a card, a license and a checksum.

## Synthetic (`synthetic/`)

| Name | Rows | Purpose |
|---|---|---|
| retail_loans_dev | 15000 | default model development |
| retail_loans_monitoring | 6000 | drift monitoring |
| loan_book | 5000 | ECL inputs |
| market_returns | 3000 | daily returns for the method modules |

Regenerate with `python tools/build_datasets.py`. The output is deterministic, so the checksums in the cards must not change.

## Real (`raw/` and `processed/`)

| Name | Rows | License | Used by |
|---|---|---|---|
| german_credit | 1000 | CC BY 4.0 | credit_decision_cutoff |
| wti_spot_daily | 9547 | ODC-PDDL-1.0 | var_crisis_research |
| fx_daily_2000 (processed) | 7015 | ODC-PDDL-1.0 | var_crisis_research, daily_market_risk_desk |
| sp500_shiller_monthly | 1869 | ODC-PDDL-1.0 | historical_stress_replay |

Download again with `python tools/fetch_real_data.py` (needs internet). The script writes the files and the cards. `german_credit` comes from the scorecardpy package, which holds the same table as UCI with text labels, and the card says that a cell by cell comparison with the UCI file was not run. The trailing rows of the Shiller file have zero dividend and yield and are excluded in the notebook, and the card says so.

Files: `catalog.csv` lists every dataset with checksum. Each `<folder>/<name>.yaml` is a dataset card with source, license, changes, leakage risks and representativeness. See [docs/dataset_guide.md](../docs/dataset_guide.md).

## Disclaimer

Synthetic data does not represent any real bank, market or borrower. Real open data is public and old or aggregated. It does not represent the portfolio of any bank either. Do not describe results on it as findings about a real institution.
