# Security Policy

## Scope

This repository contains educational code and synthetic data. It holds no customer data, credentials or production systems. Please do not commit real customer, account or personal data, secrets or API keys.

## Reporting a vulnerability

Report privately through the GitHub security advisory feature of this repository (Security tab, Report a vulnerability). Include the file, the steps to reproduce and the impact. Expect an acknowledgement within 7 days. This is a maintainer goal, not a guarantee, because the project has one maintainer.

## Supported versions

Only the latest release on the default branch.

## What counts

Dependency vulnerabilities, unsafe file handling in the tools, and accidental inclusion of sensitive data. Modelling errors are not security issues. Report them as normal issues.

## Using the code in a real institution

The code is not validated for production. Any use with real data needs your own security review and model validation.
