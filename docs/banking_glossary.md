# Banking Glossary

Audience: new readers. Short definitions of terms used in the modules. Reference document.

| Term | Meaning in this repository |
|---|---|
| Exposure at default (EAD) | Amount owed at the moment of default. In the loan book it is the outstanding balance. |
| Probability of default (PD) | Chance of default within a stated horizon. The 12 month PD is the default horizon used for stage 1. |
| Loss given default (LGD) | Share of EAD not recovered, a decimal between 0 and 1. |
| Expected credit loss (ECL) | Probability weighted loss estimate, PD times LGD times EAD with discounting and staging. |
| Effective interest rate (EIR) | Rate that discounts expected cash flows to the carrying amount. Used as the discount rate for ECL. |
| Days past due (DPD) | Days since a payment was due and not made. |
| Non performing loan (NPL) | Loan in default or close to it. Definitions differ by regime. A module for NPL management is planned. |
| Value at Risk (VaR) | Loss level that is exceeded with probability 1 minus alpha over a horizon. |
| Expected Shortfall (ES) | Average loss in the tail beyond the VaR level. |
| Exception | A day when the realised loss is larger than the VaR forecast. |
| Backtesting | Comparing risk forecasts with realised outcomes. |
| Duration | First order sensitivity of price to yield. |
| Convexity | Second order sensitivity of price to yield. |
| DV01 | Price change for a one basis point move in yield. |
| Basis point | 0.01 percent. |
| Scorecard | Points based credit scoring model, usually from logistic regression on binned inputs. |
| Weight of evidence (WoE) | Log ratio of the share of good to bad accounts in a bin. |
| Information value (IV) | Sum over bins of share difference times WoE, a ranking power summary. |
| Population stability index (PSI) | Distance between two distributions of the same variable, used for drift monitoring. |
| Gini, AUC, KS | Ranking power measures for a risk score. Gini equals 2 AUC minus 1. |
| Calibration | Agreement between predicted and observed default rates. |
| Covariate shift | The input distribution changes while the relation between inputs and default stays the same. |
| Stage 1, 2, 3 | IFRS 9 buckets: performing, significant increase in credit risk, credit impaired. |
| SICR | Significant increase in credit risk since origination. The test used here is a documented simplification. |
| Synthetic data | Data generated by code in this repository, with known parameters. |

## Check before use

Definitions of NPL, default and stage criteria are regime specific. Use the primary text of your regulator and accounting standard, not this table.
